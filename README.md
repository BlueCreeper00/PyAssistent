# Bem-vindo ao **PyAssistent**



\### \*Seu inicializador de arquivos em Python\*



\## O que é?

Um app feito em Python para agilizar seu dia a dia.



\## O que faz?

Busca arquivos para você. Digite "jogar", por exemplo, e ele abre seu Steam.



\## E se não tenho o Steam?

Se você não tiver o Steam instalado, ele abre o Xbox.



\## Comandos

Digitando "ajuda" ou "help", um guia de comandos é aberto.



\## E se não tenho o Python?

Será disponibilizada uma versão .exe na página do PyAssistent no GitHub.
