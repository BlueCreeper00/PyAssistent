**## COMANDOS**



**- \*\*ajuda/help\*\* - abre esse guia**

**- \*\*jogar/play\*\* - abre o Steam/Xbox**

**- \*\*programar/code\*\* - abre o Python**

**- \*\*navegar/internet\*\* - abre o seu navegador padrão**

**- \*\*arquivos/files\*\* - abre o File Explorer**

**- \*\*nota/note\*\* - abre o Bloco de Notas**

**- \*\*calc\*\* - abre a calculadora**

**- \*\*cmd\*\* - abre o Prompt de Comando**

**- \*\*config\*\* - abre as Configurações**

**- \*\*sair/fechar/exit\*\* - fecha o PyAssistent**

**- \*\*desligar/shutdown\*\* - desliga o computador**

**- \*\*reiniciar/restart\*\* - reinicia o computador**
